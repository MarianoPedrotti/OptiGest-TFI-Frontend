# OptiGest - Frontend

Repositorio academico del frontend de OptiGest, presentado como Trabajo Final
Integrador de la Tecnicatura Universitaria en Programacion.

## Tecnologias

- Vue 3, TypeScript y Vite
- Pinia para estado de aplicacion
- Vue Router y Axios para navegacion e integracion con la API
- Bootstrap y Chart.js para interfaz y visualizacion

## Funcionalidades

- Inicio de sesion y manejo de sesion autenticada.
- Gestion de clientes, productos, vehiculos y usuarios.
- Operacion de ventas, pagos, financiaciones y cuenta corriente.
- Dashboard, filtros y estados de ventas.

## Configuracion local

La API se define mediante `VITE_API_URL`. La configuracion de produccion usa
`/api`; no hay URLs, tokens ni credenciales de produccion en esta copia.
